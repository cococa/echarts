## 🎨 统一特性

所有测试页面都包含以下功能：

### 1. 交互控制
- **渲染器切换**: Canvas / SVG
- **粗糙度调节**: 0 - 5 (步长 0.1)
- **填充样式选择**: 7 种样式
  - hachure (斜线)
  - solid (实心)
  - zigzag (锯齿)
  - cross-hatch (交叉线)
  - dots (点)
  - dashed (虚线)
  - zigzag-line (锯齿线)

### 2. 操作按钮
- **应用设置**: 使用新参数重新创建图表
- **刷新图表**: 调整图表大小

### 3. 字体支持
- 使用自定义手写字体: **JinNianYeYaoJiaYouYa-2**
- 通过全局 `textStyle` 设置，代码更简洁
- 字体应用于所有文本元素（标题、图例、坐标轴等）

## 💡 代码优化

### 全局字体设置

所有页面都采用统一的全局字体配置方式：

```javascript
const option = {
    textStyle: {
        fontFamily: 'JinNianYeYaoJiaYouYa, sans-serif'
    },
    title: {
        text: '图表标题'
    },
    // ... 其他配置
};
```

**优点**:
- ✅ 代码更简洁，无需在每个组件中单独设置
- ✅ 统一管理，易于维护
- ✅ 自动应用到所有文本元素
- ✅ 提供降级方案 (sans-serif)

### 字体加载

在 CSS 中统一加载字体：

```css
@font-face {
    font-family: 'JinNianYeYaoJiaYouYa';
    src: url('../../JinNianYeYaoJiaYouYa-2.ttf') format('truetype');
    font-weight: normal;
    font-style: normal;
}
```

## 📊 测试建议

### 基础测试流程
1. 打开测试页面
2. 保持默认配置 (Canvas, Roughness: 2.6, Filler: hachure)
3. 观察默认手绘效果
4. 调整 roughness 值，对比不同强度
5. 切换 filler 样式，对比不同填充效果
6. 切换到 SVG 渲染器，确认无报错

1. 打开浏览器开发者工具 (F12)
2. 切换到 Performance 标签
3. 点击"应用设置"按钮
4. 记录渲染时间
5. 对比不同 roughness 值的性能影响

## 🔧 自定义扩展

### 添加新的图表类型

参考现有页面结构，创建新的测试页面：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>Roughness [图表类型]调试</title>
    <!-- 引入必要的库和样式 -->
    <style>
        @font-face {
            font-family: 'JinNianYeYaoJiaYouYa';
            src: url('../../JinNianYeYaoJiaYouYa-2.ttf') format('truetype');
        }
        /* ... 其他样式 */
    </style>
</head>
<body>
    <!-- 控制面板 -->
    <div class="controls">
        <!-- 渲染器、粗糙度、填充样式选择 -->
    </div>
    
    <!-- 图表容器 -->
    <div id="main"></div>
    
    <script>
        // 图表配置
        const option = {
            textStyle: {
                fontFamily: 'JinNianYeYaoJiaYouYa, sans-serif'
            },
            // ... 图表配置
        };
    </script>
</body>
</html>
```

### 修改默认参数

在 JavaScript 代码中修改初始值：

```javascript
let currentRenderer = 'canvas';  // 或 'svg'
let currentRoughness = 2.6;      // 0 - 5
let currentFiller = 'hachure';   // 填充样式
```
