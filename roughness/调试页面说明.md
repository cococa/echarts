# Roughness 调试页面使用说明

## 页面列表

我们提供了三个独立的调试页面，用于测试不同图表类型的手绘风格效果：

1. **折线图调试**: `echarts/test/roughness/roughness-line-debug.html`
2. **柱状图调试**: `echarts/test/roughness/roughness-bar-debug.html`
3. **饼图调试**: `echarts/test/roughness/roughness-pie-debug.html`

## 功能特性

### 1. 自定义字体支持

所有页面都使用了自定义手写字体 **JinNianYeYaoJiaYouYa-2**，增强手绘风格的整体效果。

字体应用位置：
- 图表标题
- 图例文字
- 坐标轴标签
- 饼图标签

### 2. 交互控制

每个页面都提供以下可调节参数：

#### 渲染器 (Renderer)
- **Canvas**: 支持完整的 roughness 手绘效果
- **SVG**: 不支持 roughness（但保证不报错）

#### 粗糙度 (Roughness)
- **范围**: 0 - 5
- **步长**: 0.1
- **默认值**: 2.6
- **效果**: 
  - 0: 无手绘效果，正常渲染
  - 1-2: 轻微手绘效果
  - 2-3: 中等手绘效果（推荐）
  - 3-5: 强烈手绘效果

#### 填充样式 (Filler)
- **hachure** (斜线): 经典的手绘斜线填充，最常用
- **solid** (实心): 实心填充，边缘有手绘效果
- **zigzag** (锯齿): 锯齿状填充
- **cross-hatch** (交叉线): 交叉斜线填充，更密集
- **dots** (点): 点状填充
- **dashed** (虚线): 虚线填充
- **zigzag-line** (锯齿线): 锯齿线条填充

### 3. 操作按钮

- **应用设置**: 使用当前选择的参数重新创建图表
- **刷新图表**: 调整图表大小（不改变参数）

## 使用步骤

### 基础使用

1. 在浏览器中打开任意调试页面
2. 页面会自动加载并显示默认配置的图表
3. 调整参数（渲染器、粗糙度、填充样式）
4. 点击"应用设置"按钮查看新效果
5. 打开浏览器控制台 (F12) 查看详细日志

### 对比测试

**测试手绘效果强度**:
```
1. 设置 roughness = 0，点击"应用设置" → 查看正常效果
2. 设置 roughness = 1.5，点击"应用设置" → 查看轻微手绘效果
3. 设置 roughness = 2.6，点击"应用设置" → 查看中等手绘效果
4. 设置 roughness = 4.0，点击"应用设置" → 查看强烈手绘效果
```

**测试填充样式**:
```
1. 保持 roughness = 2.6
2. 依次选择不同的 filler 样式
3. 每次选择后点击"应用设置"
4. 对比不同填充样式的视觉效果
```

**测试渲染器兼容性**:
```
1. 在 Canvas 模式下测试，确认手绘效果正常
2. 切换到 SVG 模式，点击"应用设置"
3. 确认 SVG 模式下不报错（但无手绘效果）
```

## 各图表类型特点

### 折线图 (Line Chart)

**测试重点**:
- 折线的手绘效果
- 多条折线的视觉区分
- 数据点标记的手绘效果

**推荐配置**:
- Roughness: 2.0 - 3.0
- Filler: hachure 或 solid

### 柱状图 (Bar Chart)

**测试重点**:
- 矩形柱子的手绘边框
- 填充样式的视觉效果
- 多组柱子的对比

**推荐配置**:
- Roughness: 2.5 - 3.5
- Filler: hachure、cross-hatch 或 zigzag

### 饼图 (Pie Chart)

**测试重点**:
- 扇形的手绘边框
- 扇形填充的手绘效果
- 多个扇形的整体协调性

**推荐配置**:
- Roughness: 2.0 - 3.0
- Filler: hachure、solid 或 dots

## 调试技巧

### 1. 查看控制台日志

打开浏览器开发者工具 (F12)，在 Console 标签页可以看到：
- 图表创建信息
- 渲染器类型
- Roughness 和 Filler 参数
- 元素绘制的详细日志

### 2. 性能测试

```javascript
// 在控制台中执行
console.time('render');
// 点击"应用设置"按钮
console.timeEnd('render');
```

### 3. 检查元素属性

在控制台中执行：
```javascript
const zr = chart.getZr();
console.log('Roughness:', zr.roughness);
console.log('Filler:', zr.filler);
console.log('Renderer:', zr.painter.type);
```

### 4. 动态修改参数

在控制台中执行：
```javascript
// 动态修改 roughness
const zr = chart.getZr();
zr.roughness = 3.5;
chart.setOption(chart.getOption(), true);
```

## 常见问题

### Q1: 为什么 SVG 模式下没有手绘效果？

**A**: SVG 渲染器不支持 roughness 效果。这是设计限制，因为 rough.js 库主要针对 Canvas 渲染。但 SVG 模式下不会报错，可以正常显示图表。

### Q2: 如何调整手绘效果的强度？

**A**: 通过调整 roughness 参数：
- 0: 无效果
- 1-2: 轻微
- 2-3: 中等（推荐）
- 3-5: 强烈

### Q3: 不同 filler 样式有什么区别？

**A**: 
- **hachure**: 最常用，经典手绘斜线
- **solid**: 实心填充，适合需要清晰显示的场景
- **cross-hatch**: 交叉线，更有艺术感
- **dots**: 点状，适合轻量级视觉效果
- **zigzag**: 锯齿状，独特的视觉风格

### Q4: 为什么字体显示不正常？

**A**: 确保字体文件 `JinNianYeYaoJiaYouYa-2.ttf` 存在于 `echarts/` 目录下。如果字体加载失败，会自动降级到系统默认字体。

### Q5: 如何保存当前配置？

**A**: 可以在控制台中查看当前配置：
```javascript
console.log({
    renderer: document.getElementById('renderer').value,
    roughness: document.getElementById('roughness').value,
    filler: document.getElementById('filler').value
});
```

## 最佳实践

### 1. 推荐配置组合

**轻量手绘风格**:
```
Roughness: 1.5
Filler: solid
适用场景: 需要保持清晰度的专业图表
```

**标准手绘风格**:
```
Roughness: 2.6
Filler: hachure
适用场景: 大多数手绘风格需求
```

**强烈手绘风格**:
```
Roughness: 3.5
Filler: cross-hatch
适用场景: 艺术性强、创意性展示
```

### 2. 性能优化建议

- 数据量大时，适当降低 roughness 值
- 复杂图表建议使用 solid filler
- 避免在动画过程中频繁切换 roughness

### 3. 视觉设计建议

- 配合手写字体使用，整体风格更统一
- 选择柔和的配色方案
- 避免过于复杂的图表结构
- 适当增加元素间距，避免视觉拥挤
