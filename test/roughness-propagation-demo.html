🎨 Roughness 属性传递机制演示

问题：为什么 ZRender 初始化时设置了 roughness，但图形元素却没有应用手绘风格？ 已修复 ✓

原因：属性不会自动继承，需要在元素添加到 ZRender 时显式传递

📊 测试图表 (roughness: 5)
📈 实时统计

🔍 详细分析

💡 核心问题

1. ZRender 实例有 roughness 属性

2. 但图形元素（Rect, Line, Text 等）在创建时没有这个属性

3. 需要在元素添加到 ZRender 时，从 ZRender 实例获取并设置

✅ 修复方案

修改 1: Element.addSelfToZr() - 在检查 __zr 之前设置 roughness

addSelfToZr(zr: ZRenderType) {
    // ✓ 先设置属性（在检查之前）
    if (zr.roughness != null && this.roughness == null) {
        this.roughness = zr.roughness;
    }
    
    // 然后检查是否已经添加
    if (this.__zr === zr) {
        return;
    }
    
    this.__zr = zr;
    // ...
}

修改 2: Group._doAdd() - 处理已有 __zr 的子元素

_doAdd(child: Element) {
    // ...
    const zr = this.__zr;
    if (zr && zr !== (child as Group).__zr) {
        child.addSelfToZr(zr);
    }
    // ✓ 新增：即使已有相同的 __zr，也要同步 roughness
    else if (zr && zr === (child as Group).__zr) {
        if (zr.roughness != null && child.roughness == null) {
            child.roughness = zr.roughness;
        }
    }
    // ...
}
